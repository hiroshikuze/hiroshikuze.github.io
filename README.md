# hiroshikuze.github.io

SEO/AIO measures for <https://hiroshikuze.github.io/>

Hiroshi Kuze（京都）の個人サイトのソースコードです。

This repository contains the source code of my personal site, Hiroshi Kuze (Kyoto, Japan).

## 概要 / Overview

このリポジトリは、GitHub Pagesで公開している個人サイト <https://hiroshikuze.github.io/> のソースです。

This repository is the source of my personal site published with GitHub Pages at <https://hiroshikuze.github.io/>.

## デモ / Demo

[![Demo](https://img.shields.io/badge/Demo-Open%20Site-22c55e?style=for-the-badge&logo=github&logoColor=white)](https://hiroshikuze.github.io/)

## 使用技術 / Tech Stack

- HTML（静的サイト、GitHub Pagesで配信）
  - HTML (static site, served by GitHub Pages)
- 構造化データ（JSON-LD：WebSite・Person）
  - Structured data (JSON-LD: WebSite, Person)
- アクセス解析：umami
  - Analytics: umami
- デザイン：[Hyperspace](https://html5up.net/hyperspace)（HTML5 UP）を改変して使用
  - Design: modified [Hyperspace](https://html5up.net/hyperspace) by HTML5 UP
- jQuery・Font Awesome Free（アイコン）・Noto Sans JP（Google Fonts）
  - jQuery, Font Awesome Free (icons) and Noto Sans JP (Google Fonts)
