# rules/coding.md — コーディング規約

すべてYes/Noで判定できる条件として記述。Noの場合は修正してから進む。

---

## 変更前チェック

- [ ] 編集するファイルを事前にReadツールで読んだか？
- [ ] 変更範囲は依頼された内容のみか（依頼されていないリファクター・コメント追加を含んでいないか）？
- [ ] 新しいファイルを作成する前に、既存ファイルへの追記で対応できないか確認したか？

## コード品質

- [ ] OWASP Top 10（XSS等）を導入していないか？
- [ ] 使われなくなったコードを残していないか？（後方互換シムを作らず削除する）
