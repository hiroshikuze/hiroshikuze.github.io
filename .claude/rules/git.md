# rules/git.md — Git Workflow

すべてYes/Noで判定できる条件として記述。Noの場合は修正してから進む。

---

## ブランチ

- [ ] 作業ブランチは `claude/<slug>` 形式か？
- [ ] `main` への直接プッシュではないか？（ユーザーの明示的な許可がある場合を除く）
- [ ] PR作成はユーザーから明示的に依頼されたか？（依頼なしでは作成しない）
- [ ] 操作対象は `hiroshikuze/hiroshikuze.github.io` のみか？

## コミット

- [ ] コミットメッセージは日本語の命令形か？
- [ ] 1コミットに含まれる変更は1つの論理的な変更のみか？
- [ ] 公開済みコミットを `--amend` していないか？（修正は新規コミットで行う）
- [ ] `.env` やAPIキーなどの秘密情報をコミットしていないか？

## プッシュ

- [ ] `git push -u origin <branch-name>` の形式を使っているか？
- [ ] `--force` オプションをユーザーの明示的な指示なしに使っていないか？

## プルリクエスト

- [ ] PRのタイトル・本文（Summary・Test plan含む）は日本語で書いているか？
- [ ] `rules/writing.md` に沿っているか？
- [ ] GitHub Issue由来の依頼か？→ Yesならその対応PRの本文に`Closes #<issue番号>`を含めたか？
- [ ] PRの`main`へのマージはユーザーが自分で行うか？
